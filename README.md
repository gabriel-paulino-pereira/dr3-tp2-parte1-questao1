FastAPI - Parte 1: Questão 1

Aplicação desenvolvida em FastAPI estruturada para fins acadêmicos, integrando endpoints de alta performance com validação de dados via Pydantic.
Tecnologias Utilizadas

    Python 3.10+

    FastAPI

    Uvicorn

Como Executar

    Crie e ative um ambiente virtual executando no PowerShell:
    python -m venv venv
    .\venv\Scripts\Activate

    Instale as dependências executando:
    pip install fastapi uvicorn

    Execute o servidor de desenvolvimento executando:
    uvicorn main:app --reload

    Acesse a documentação interativa (Swagger UI) no navegador em:
    http://127.0.0.1:8000/docs
